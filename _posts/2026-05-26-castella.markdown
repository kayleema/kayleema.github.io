### Ingredients:
   - **Bread (or all-purpose) flour (100g)**
   - **Sugar (100g)**
   - **Eggs 4**
   - **Mirin (2 Tablespoons / 30mL)**
   - **Honey (2 Tablespoons / 30mL)**
   - **Oil (2 Tablespoons / 30mL)**

----

2. Line an 18cm×18cm pan with parchment paper
    - Optionally spread 30g of dark brown sugar or coarse sugar on the bottom of the pan for extra sweetness and flavor or texture
3. **Sift the flour (100g)** into a separate bowl for later
4. **Beat eggs (4) and sugar (100g)** in a bowl partially submerged in an additional bowl of 40°C water until ribbons
5. Preheat oven to 180°C
6. **Add remaining wet ingredients** and mix at low speed
    - Mirin: 2 Tablespoons (30mL)
    - Honey: 2 Tablespoons (30mL)
    - Oil: 2 Tablespoons (30mL)
7. **Fold in the flour**
8. Pour into lined baking pan
9. Drop the pan from ~10cm onto a hard countertop several times to release bubbles
10. <strong>Bake <mark>180°C for 10min</mark> then <mark>140°C for 40min</mark></strong>

<small>
<strong>Notes on United States Customary Unit Conversion:</strong>
While a United States customary liquid tablespoon is technically 14.8 mL, in practice United States Tablespoons are 15mL which is the same as most other countries including Japan.
While it is recommended to use weigh units for sugar and flour, an approximate conversion to United States Customary Volume units results in approximately 0.8 Cups of flour and 0.5 Cups of sugar.
</small>

Electricity Cost estimate calculation source code:
```javascript
// --- Inputs ---
const ovenW      = 1200;   // oven wattage (W)
const preheatMin = 10;     // preheat duration (min)
const dutyPH     = 0.90;   // preheat duty cycle (0–1)
const bake1Min   = 10;     // bake phase 1 duration (min) at 180°C
const duty1      = 0.55;   // duty cycle during phase 1
const bake2Min   = 40;     // bake phase 2 duration (min) at 140°C
const duty2      = 0.40;   // duty cycle during phase 2
const mixerW     = 150;    // hand mixer wattage (W)
const mixerMin   = 10;     // mixing duration (min)
const yenPerKWh  = 35;     // Tokyo electricity rate (¥/kWh)

// --- Calculations ---
const preheatKWh = (ovenW / 1000) * (preheatMin / 60) * dutyPH;
const bake1KWh   = (ovenW / 1000) * (bake1Min   / 60) * duty1;
const bake2KWh   = (ovenW / 1000) * (bake2Min   / 60) * duty2;
const mixerKWh   = (mixerW / 1000) * (mixerMin  / 60);
const totalKWh   = preheatKWh + bake1KWh + bake2KWh + mixerKWh;
const totalYen   = totalKWh * yenPerKWh;

// --- Output ---
console.log("=== Castella electricity cost ===");
console.log(`Preheat  (${preheatMin} min, ${dutyPH*100}% duty): ${preheatKWh.toFixed(4)} kWh = ¥${(preheatKWh * yenPerKWh).toFixed(2)}`);
console.log(`Bake 180°C (${bake1Min} min, ${duty1*100}% duty): ${bake1KWh.toFixed(4)} kWh = ¥${(bake1KWh * yenPerKWh).toFixed(2)}`);
console.log(`Bake 140°C (${bake2Min} min, ${duty2*100}% duty): ${bake2KWh.toFixed(4)} kWh = ¥${(bake2KWh * yenPerKWh).toFixed(2)}`);
console.log(`Mixer    (${mixerMin} min):               ${mixerKWh.toFixed(4)} kWh = ¥${(mixerKWh * yenPerKWh).toFixed(2)}`);
console.log("---");
console.log(`Total: ${totalKWh.toFixed(4)} kWh = ¥${totalYen.toFixed(2)}`);
```
