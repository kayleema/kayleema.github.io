4人分

* 玉ねぎ 1個（みじん切り）
* にんにく 2片
* ピーマン 3〜4個 または 緑パプリカ 1個

* 豚ひき肉／牛ひき肉 200〜300g

* 缶詰カットトマト 800g

* オレガノ 約1/4 tsp
* タイム 約1/4 tsp
* バジル 1/2 tsp
* 塩 2 tsp
* 黒こしょう
* 赤唐辛子 3本

----

1. 玉ねぎをみじん切りにし、にんにくをすりつぶす。
2. フライパンに油を熱し、中強火で玉ねぎ、にんにく、ピーマンを約5分炒める。
3. ひき肉を加え、塩の半量を振り、ほぐしながら炒めて色が変わるまで火を通す。
4. 缶詰トマトを加え、オレガノ、タイム、バジル、黒こしょう、赤唐辛子を入れる。
5. 残りの塩を加え、弱火で25分ほど煮込む（時々かき混ぜ、味を見て調整する）。
6. スパゲッティを袋の表示通りに茹で、ソースをかけて盛り付ける。

### パスタの電気代試算

```
炒め（玉ねぎ・にんにく）（5分、デューティ比85%）：0.0992 kWh ＝ ¥3.47
肉の炒め             （5分、デューティ比85%）：0.0992 kWh ＝ ¥3.47
ソースの煮込み         （25分、デューティ比20%）：0.1167 kWh ＝ ¥4.08
パスタ用湯沸かし       （10分、デューティ比100%）：0.3667 kWh ＝ ¥12.83
パスタ茹で            （10分、デューティ比40%）：0.1467 kWh ＝ ¥5.13
---
合計：0.8283 kWh ＝ ¥29.00
```

電気代試算のソースコード：
```javascript
// --- 入力値 ---
const sauceBurnerW   = 1400;   // IHソースバーナー消費電力（W）
const pastaBurnerW   = 2200;   // IHパスタ鍋バーナー消費電力（W）
const sauteMin       = 5;      // 玉ねぎ・にんにく炒め時間（分）
const dutySaute      = 0.85;   // 炒めのデューティ比（0〜1）
const brownMin       = 5;      // 肉の炒め時間（分）
const dutyBrown      = 0.85;   // 肉炒めのデューティ比
const simmerMin      = 25;     // ソース煮込み時間（分）
const dutySimmer     = 0.20;   // 煮込みのデューティ比
const boilMin        = 10;     // 湯沸かし時間（分）
const dutyBoil       = 1.00;   // 湯沸かしのデューティ比
const cookPastaMin   = 10;     // パスタ茹で時間（分）
const dutyCookPasta  = 0.40;   // パスタ茹でのデューティ比
const yenPerKWh      = 35;     // 東京の電気料金（円/kWh）

// --- 計算 ---
const sauteKWh      = (sauceBurnerW / 1000) * (sauteMin      / 60) * dutySaute;
const brownKWh      = (sauceBurnerW / 1000) * (brownMin      / 60) * dutyBrown;
const simmerKWh     = (sauceBurnerW / 1000) * (simmerMin     / 60) * dutySimmer;
const boilKWh       = (pastaBurnerW / 1000) * (boilMin       / 60) * dutyBoil;
const cookPastaKWh  = (pastaBurnerW / 1000) * (cookPastaMin  / 60) * dutyCookPasta;
const totalKWh      = sauteKWh + brownKWh + simmerKWh + boilKWh + cookPastaKWh;
const totalYen      = totalKWh * yenPerKWh;

// --- 出力 ---
console.log("=== パスタの電気代 ===");
console.log(`炒め（玉ねぎ・にんにく）（${sauteMin}分、${dutySaute*100}%デューティ）：${sauteKWh.toFixed(4)} kWh ＝ ¥${(sauteKWh * yenPerKWh).toFixed(2)}`);
console.log(`肉の炒め             （${brownMin}分、${dutyBrown*100}%デューティ）：${brownKWh.toFixed(4)} kWh ＝ ¥${(brownKWh * yenPerKWh).toFixed(2)}`);
console.log(`ソースの煮込み         （${simmerMin}分、${dutySimmer*100}%デューティ）：${simmerKWh.toFixed(4)} kWh ＝ ¥${(simmerKWh * yenPerKWh).toFixed(2)}`);
console.log(`パスタ用湯沸かし       （${boilMin}分、${dutyBoil*100}%デューティ）：${boilKWh.toFixed(4)} kWh ＝ ¥${(boilKWh * yenPerKWh).toFixed(2)}`);
console.log(`パスタ茹で            （${cookPastaMin}分、${dutyCookPasta*100}%デューティ）：${cookPastaKWh.toFixed(4)} kWh ＝ ¥${(cookPastaKWh * yenPerKWh).toFixed(2)}`);
console.log("---");
console.log(`合計：${totalKWh.toFixed(4)} kWh ＝ ¥${totalYen.toFixed(2)}`);
```

備考：調理時間は想定値です（炒め5分、肉炒め5分、煮込み25分、湯沸かし10分、パスタ茹で10分）。IHコンロはソース用1400W、パスタ鍋用2200Wを使用。
