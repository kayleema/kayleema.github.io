### 材料：
   - **薄力粉（100g）**
   - **砂糖（100g）**
   - **卵 4個**
   - **みりん（大さじ2 / 30mL）**
   - **はちみつ（大さじ2 / 30mL）**
   - **油（大さじ2 / 30mL）**

----

2. 18cm×18cmの型にクッキングシートを敷く
    - お好みで、黒砂糖またはザラメ30gを型の底に広げると甘みや風味・食感がアップします
3. **薄力粉（100g）をふるって**別のボウルに入れておく
4. **卵（4個）と砂糖（100g）を**40℃のお湯を張った別のボウルに浸けながら、リボン状になるまで泡立てる
5. オーブンを180℃に予熱する
6. **残りの液体材料を加え**、低速で混ぜる
    - みりん：大さじ2（30mL）
    - はちみつ：大さじ2（30mL）
    - 油：大さじ2（30mL）
7. **薄力粉を折り込む**
8. 型に流し込む
9. 型を約10cmの高さから硬い台に数回落として気泡を抜く
10. <strong><mark>180°Cで10分焼き</mark>、次に<mark>140°Cで40分焼く</mark></strong>

### カステラの電気代試算

```
予熱     （10分、デューティ比90%）：0.1800 kWh ＝ ¥6.30
焼き180°C（10分、デューティ比55%）：0.1100 kWh ＝ ¥3.85
焼き140°C（40分、デューティ比40%）：0.3200 kWh ＝ ¥11.20
ミキサー （10分）                 ：0.0250 kWh ＝ ¥0.87
---
合計：0.6350 kWh ＝ ¥22.23
```

電気代試算のソースコード：
```javascript
// --- 入力値 ---
const ovenW      = 1200;   // オーブン消費電力（W）
const preheatMin = 10;     // 予熱時間（分）
const dutyPH     = 0.90;   // 予熱のデューティ比（0〜1）
const bake1Min   = 10;     // 第1焼成時間（分）180°C
const duty1      = 0.55;   // 第1焼成のデューティ比
const bake2Min   = 40;     // 第2焼成時間（分）140°C
const duty2      = 0.40;   // 第2焼成のデューティ比
const mixerW     = 150;    // ハンドミキサー消費電力（W）
const mixerMin   = 10;     // 混合時間（分）
const yenPerKWh  = 35;     // 東京の電気料金（円/kWh）

// --- 計算 ---
const preheatKWh = (ovenW / 1000) * (preheatMin / 60) * dutyPH;
const bake1KWh   = (ovenW / 1000) * (bake1Min   / 60) * duty1;
const bake2KWh   = (ovenW / 1000) * (bake2Min   / 60) * duty2;
const mixerKWh   = (mixerW / 1000) * (mixerMin  / 60);
const totalKWh   = preheatKWh + bake1KWh + bake2KWh + mixerKWh;
const totalYen   = totalKWh * yenPerKWh;

// --- 出力 ---
console.log("=== カステラの電気代 ===");
console.log(`予熱     （${preheatMin}分、${dutyPH*100}%デューティ）：${preheatKWh.toFixed(4)} kWh ＝ ¥${(preheatKWh * yenPerKWh).toFixed(2)}`);
console.log(`焼き180°C（${bake1Min}分、${duty1*100}%デューティ）：${bake1KWh.toFixed(4)} kWh ＝ ¥${(bake1KWh * yenPerKWh).toFixed(2)}`);
console.log(`焼き140°C（${bake2Min}分、${duty2*100}%デューティ）：${bake2KWh.toFixed(4)} kWh ＝ ¥${(bake2KWh * yenPerKWh).toFixed(2)}`);
console.log(`ミキサー （${mixerMin}分）               ：${mixerKWh.toFixed(4)} kWh ＝ ¥${(mixerKWh * yenPerKWh).toFixed(2)}`);
console.log("---");
console.log(`合計：${totalKWh.toFixed(4)} kWh ＝ ¥${totalYen.toFixed(2)}`);
```

備考：
米国食品医薬品局（FDA）は「栄養成分表示の目的では、1カップは240mL、大さじ1は15mLとする」と定めています。
