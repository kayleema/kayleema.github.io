KappaVM

A High-Performance Stack-Based Virtual Machine

Built in C11 with Complete Toolchain

What is KappaVM?

  • Stack-based virtual machine written in C11
  • Complete custom bytecode execution engine
  • Full toolchain: assembler, disassembler, VM runtime
  • 256-value stack with 64 concurrent call frames
  • First-class functions and prototype-based objects

Core Components

1. Virtual Machine Engine

  • Stack-based execution with 256-value capacity
  • Call frame management for function calls
  • Instruction dispatch loop with optimized opcodes

2. Instruction Set

  • 64-bit instructions: 8-bit opcode + 56-bit operand
  • Arithmetic: ADD, SUB, MUL, DIV, MOD
  • Control Flow: JMP, CALL, RETURN

Bytecode Design

Instruction Format

(8 bits)
Operand

64-bit Instruction = 8-bit Opcode + 56-bit Operand

Benefits

  • Large operand space for constants and jump offsets
  • Efficient encoding - single 64-bit value per instruction
  • Simple decoding with bit manipulation macros

Development Workflow

Build System

# Build all components
mkdir build && cd build
cmake ..
make

# Run tests
make test

# Execute programs
./kappavm program.kbc

Toolchain Usage

# Assemble source to bytecode
./kappavm --assemble source.kappa output.kbc

# Execute bytecode
./kappavm output.kbc

# Disassemble for inspection
./kappavm --dis output.kbc
